# Sistema de Estoque

## Descrição

O **Sistema de Estoque** é uma aplicação Java desenvolvida para gerenciar uma lista de produtos de forma simples e prática pelo terminal.

O sistema permite cadastrar itens, remover produtos pelo nome, consultar um item específico e exibir todos os produtos cadastrados. O projeto foi construído com foco em conceitos fundamentais de programação orientada a objetos, uso de `ArrayList`, entrada de dados com `Scanner` e manipulação de informações em memória.

---

## Funcionalidades

- Cadastrar produto
- Remover produto pelo nome
- Consultar produto pelo nome
- Listar todos os produtos cadastrados
- Encerrar o sistema pelo menu

---

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- `ArrayList`
- `Scanner`
